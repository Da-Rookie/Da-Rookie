# 25. ANIMATION SYSTEM

Use Framer Motion for:

- section reveal
- text reveal
- card reveal
- hover
- navigation
- page interaction

Use GSAP only for:

- complex scroll sequences
- hero interaction
- subtle timeline animation
- advanced cursor interaction

Animation principles:

- fast
- subtle
- intentional
- 150–700ms range depending on complexity
- never block content

Respect:

```text
prefers-reduced-motion
```

When reduced motion is enabled:

- disable parallax
- disable large transforms
- reduce reveal animations
- keep content immediately accessible
